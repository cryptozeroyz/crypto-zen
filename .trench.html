tehcscreener

public api

powered by
base urlhttps://tehcscreener.com/api/v1
  • Format. JSON over GET. No API key. CORS open to any origin. Dates are YYYY-MM-DD strings; amounts are USD. Data updates once a day. Every response carries a top-level "source": "tehcscreener.com" (on /status, source is the sync source).
  • Windows. window accepts 1d, 7d, 30d or all, counted back from the latest day in the data (the response's through), not from the current date. Other values return 400.
  • Series. Per-day arrays align index-for-index with the response's days array.
  • Errors. 400 for a bad parameter, 404 for an unknown pad, bot or chain. Body: {"detail": "..."}.
  • Versioning. v1 is additive-only: fields may be added, never renamed or removed. Breaking changes ship as v2.
  • Coverage. Launchpads and bots appear in the API automatically once they are listed on the site; ones still in review are left out. Hyperliquid perps (/bots/{bot}/perps) cover fomo and pumpapp. RWAs: robinhood.
  • Rate limit. 120 requests/min per IP. Excess requests return 429 with Retry-After and X-RateLimit-* headers.

GET/api/v1/launchpads

Every listed launchpad with its totals over the window, highest volume first.

query params

paramdefaultaccepted
window7d1d | 7d | 30d | all

response

fieldtypedescription
windowstringthe window used
throughdatelatest day in the launchpad data
padsarrayone object per (chain, pad)
pads[].chainstringchain the pad runs on
pads[].padstringpad id, as used in /launchpads/{chain}/{pad}
pads[].logo_pathstring | nullsite-relative logo path
pads[].tokens_launchedinttokens launched in the window
pads[].volume_usdnumbertrading volume in the window
pads[].trade_txnsinttrade transactions in the window
pads[].tokens_tradedintsum of the per-day count of tokens traded

example

curl "https://tehcscreener.com/api/v1/launchpads?window=30d"

GET/api/v1/launchpads/{chain}/{pad}

One launchpad: profile, daily totals and its top 50 tokens by volume. chain and pad are the values from /launchpads. Unknown or unlisted pads return 404.

query params

paramdefaultaccepted
window30d1d | 7d | 30d | all
tokenstradedtraded (any token traded on the pad) | launched (only tokens launched on it within the window)

response

fieldtypedescription
chain, pad, windowstringecho of the request
tokens_modestringthe tokens param used
profileobject | nullname, description, website_url, x_url, logo_path, banner_path, color, pad_token (the pad's own token, if any); null when no profile is set
dailyarray{day, tokens_launched, volume_usd, trade_txns} per day, ascending
top_tokensarrayup to 50, highest volume first: {token, volume_usd, trade_txns, first_day}; token is the token address, first_day its first day with activity in the window
top_tokens[].symbol, top_tokens[].namestring | nullthe token's ticker and name where we have them from the launchpad's own launch data (today rise.rich); null otherwise
top_tokens[].onchain_mcap_usdnumber | nullclosed-curve launchpads only (the pad's own protocol is the only market for its tokens; today solana/rise.rich): market cap from the protocol's own onchain price × emitted supply, latest day in the last 14; null when none. Absent for every other launchpad
top_tokens[].onchain_change_1dnumber | nullclosed-curve launchpads only: day-over-day price change over the last two full days, as a fraction (0.05 = +5%), from the protocol's own onchain price; null when the token did not trade on both days. Absent for every other launchpad

example

curl "https://tehcscreener.com/api/v1/launchpads/solana/pumpfun?window=7d&tokens=launched"

GET/api/v1/bots

Daily volume, transactions and fees for trading bots (terminals), one series per bot or per chain, highest total volume first. Lists the bots shown in comparisons on the site; a few published bots stand alone (their own page only) and are left out here, but still answer on /bots/{bot}. (Not in v1: the site's own /api/bots also carries a standalone directory of those bots for site search; v1 omits it.)

query params

paramdefaultaccepted
window30d1d | 7d | 30d | all
chainallall, or one chain from the response's chains list
groupbotbot (a series per bot) | chain (a series per chain)

response

fieldtypedescription
window, chain, groupstringecho of the request
chainsstring[]every chain with data from a bot in this list
throughdatelatest day in the bot data
daysdate[]every day with data in the window, ascending
seriesarrayone object per bot (or chain)
series[].namestringbot id (or chain), as used in /bots/{bot}
series[].display_namestringdisplay name; falls back to name
series[].colorstring | nullchart color on the site
series[].logo_pathstring | nullsite-relative logo path
series[].volume_usdnumber[]volume per day, aligned to days; rounded to cents
series[].txnsint[]transactions per day
series[].fees_usdnumber[]fees per day; rounded to cents

example

curl "https://tehcscreener.com/api/v1/bots?window=7d&group=bot"

GET/api/v1/bots/{bot}

One trading bot: profile, lifetime totals, per-chain daily series and its top 50 tokens. bot is a name from /bots (case-insensitive), or a standalone published bot that /bots leaves out. Unknown or unlisted bots return 404.

query params

paramdefaultaccepted
windowall1d | 7d | 30d | all

response

fieldtypedescription
botstringbot id, lowercased
display_namestringdisplay name; falls back to bot
color, logo_path, website_url, x_url, descriptionstring | nullprofile fields
windowstringthe window used
throughdatelatest day in the bot data
first_daydatethe bot's first day with data
totalsobject{volume_usd, fees_usd, txns}, lifetime (ignores window)
daysdate[]days with data in the window, ascending
wallets_dedup(int | null)[]per day, aligned to days: deduplicated wallet count where the source provides one, else null
seriesarrayone object per chain, highest volume first
series[].namestringchain
series[].display_name, series[].colorstringchain display name (falls back to name) and color
series[].volume_usd / txns / fees_usd / walletsnumber[]per day, aligned to days
tokens_sincedate | nullfirst day of per-token data for this bot
token_windowsstring[]the window values this bot's token data covers for top_tokens: always 1d and 7d; 30d when token data spans the last 30 days of the volume series; all when it starts with the volume series (3 days of tolerance)
top_tokensarrayup to 50, highest volume first: {chain, token, volume_usd, txns, peak_wallets, first_day, last_day}; peak_wallets is the highest single-day wallet count; tokens only: quote-to-quote swaps (no attributable token) are left out of the ranking but stay in every total. Per-token data covers only tokens that reached 25 or more wallets on some day on some terminal, from 30 days before the first such day on; a token that never did is absent from every window, however high its volume, and for all a token's days before that start are left out, so its volume_usd and txns can read low and first_day late

example

curl "https://tehcscreener.com/api/v1/bots/axiom?window=30d"

Daily Hyperliquid perps volume, fees, trades and traders for a project, from its Hyperliquid builder codes. bot is a name from /bots. Perps volume is notional and is not included in /bots or /bots/{bot}.

response

fieldtypedescription

first_daydate | nullthe bot's first day with perps data; null when days is empty
throughdate | nullthe bot's latest day with perps data; null when days is empty

fees_usdnumber[]the project's builder fees in USD

GET/api/v1/rwa

Tokenized real-world assets per chain, one row per day and chain.

volume_usd: daily volume of every pool that holds a tokenized asset. Routed swaps count in each pool they pass through. Pools of two tokenized assets are excluded.

value_usd: end-of-day supply times closing price, summed over the chain's tokenized assets. Wrapped tokens are excluded, since their underlying is already counted. A token without a price uses its last price for up to 7 days, then is excluded until priced again.

query params

paramdefaultaccepted
chainallone chain, e.g. robinhood; a chain with no data returns empty rows
fromfirst dayYYYY-MM-DD, inclusive; anything else returns 400
tolatest dayYYYY-MM-DD, inclusive; anything else, or a date before from, returns 400

response

fieldtypedescription
throughdate | nulllatest day in the data for chain, whatever from and to say; null when there is none
rowsarrayone object per day and chain, days ascending
rows[].daydateUTC day
rows[].chainstringthe chain
rows[].volume_usdnumberpool volume that day; 0 on a day with value and no trading
rows[].value_usdnumber | nulltotal value at the end of that day; null when the chain has no value that day
rows[].swapsintswaps that day, per pool
rows[].assets_tradedintdistinct tokenized assets with volume that day
rows[].assets_valuedinttokenized assets priced in value_usd that day

example

curl "https://tehcscreener.com/api/v1/rwa?chain=robinhood&from=2026-10-01&to=2026-10-31"

GET/api/v1/trench

Composite 0–100 activity score for launchpads and trading bots, percentile-ranked against a trailing 90-day window and blended by weight. Only days with both launchpad and bot data count; a day is scored once 30 such days of history exist.

query params

none

response

fieldtypedescription
todayobject | nulllatest scored day; null when there is not enough history yet
today.daydatethe scored day
today.scoreint0–100
today.bandstringded | cold | active | hot | euphoric
today.componentsobjectkeyed pad_volume, tokens_launched, bot_volume, bot_fees; each {value, percentile}: the day's raw total and its 0–100 blended percentile (see method.blend)
historyarray{day, score} for every scored day, oldest first
trackedobject{launchpads, terminals}: how many listed launchpads (with any data) and listed trading bots are covered
method.window_daysintshort trailing window length (90)
method.window_days_longintlong trailing window length (365)
method.blendobject{short, long}: how the two windows' percentiles combine (sums to 1)
method.cooldownfloatscore drops decay by this factor per day; rises apply same-day
method.weightsobjectcomponent → weight (sums to 1)
method.bandsobjectband → score range; omitted when today is null

example

curl https://tehcscreener.com/api/v1/trench
