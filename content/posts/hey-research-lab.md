**HEY Research Lab 是一个面向 Robinhood Chain 的“项目开发活动与证据数据层”**：通过代码仓库、版本发布、合约部署和项目官网等公开来源，回答“这个项目是否仍有人在建设、最近交付了什么”，而不是根据币价、交易量或钱包行为给出买卖建议

* **产品层面偏积极**：定位清晰，产品已经上线，数据覆盖面较大，开发活跃，并且针对 API、MCP、AI Agent 做了较完整的机器接口。
* **商业化仍处早期**：研究请求、赏金、API 额度等代币用途已经落地，但实际付费研究和外部 API 使用规模仍小。
* **透明度存在短板**：团队匿名，生产代码并非全部开放，金库支出和创作者税尚未完整进入公开账本。
* **\$HEY 风险明显高于产品本身**：市值较小、近期涨幅较大、实际交易深度薄，且代币不分享收入、不产生收益。

## 解决的问题与产品机制

在无需许可的链上环境中，发行代币和制作官网的门槛很低，但外部用户很难判断：

* 项目是否真的有团队持续开发；
* 代币、官网、GitHub 和合约是否属于同一个项目；
* 最近的“利好”是实际产品交付，还是营销公告；
* 一个项目是否仍在建设，只是尚未获得市场关注。

HEY 将这些问题转化为**可索引、可追溯的开发证据记录**，主要服务于交易者、研究人员、项目方，以及需要自动读取研究结论的 AI Agent。


### 数据与评价方式

HEY 记录的“交付”包括版本发布、合约部署、集成、SDK、文档及部分社区型项目的实际作品；营销公告、赠品和宣传帖不会被计为建设活动。机器人提交、重复自动化提交以及只修改文档或依赖版本的提交，也会被排除或降级处理。

其 Build Momentum 评分由五部分组成：

* 交付近期程度：35%；
* 交付持续性：25%；
* 交付重要性：20%；
* 证据质量：15%；
* 来源多样性：5%。

**这一设计的优点**是把“建设”和“价格”分开，并尝试抑制刷提交、刷发布等行为；**局限**是评分仍由项目自己设计和执行，公开代码活动也不能完整代表私有开发、产品质量或商业前景。


## 产品进展与真实采用情况

### 1. 数据覆盖已经具备一定规模

截至本次查询，官网披露：

* 已发布项目页面：5,630 个；
* Research-ready 项目：1,598 个；
* Robinhood Chain Verified Builders：1,452 个；
* 当前活跃建设者：545 个；
* 当前 Shipping 状态项目：238 个。

这说明 HEY 已不只是概念产品，而是形成了较大规模的项目数据库。不过，“收录量”不等于“活跃用户使用量”，其中也包含大量没有建设证据或没有活跃市场的项目。

### 2. 项目自身开发较活跃

HEY 自身页面记录其已连续 12 周出现有效交付，过去 30 天有 18 次计入统计的交付；公开代码维度显示过去 60 天有 46 个活动日、3 名贡献者和 22 次 GitHub Release。

这与产品持续更新相互印证，但仍需注意：**这是 HEY 使用自己的规则评价自己，不属于独立第三方评级。**

### 3. 外部使用和付费需求仍偏早

状态页显示，本月带 API Key 的请求为 13,265 次，来自 16 个账户；上月为 41,774 次。

研究经济数据则显示，目前仅完成：

* 1 次付费研究请求；
* 14 次免费研究请求；
* 1 项已完成赏金；
* 0 篇已批准研究笔记；
* 0 轮研究资金投票。

所以，**HEY 已证明“能生产数据”，但尚未充分证明“市场愿意持续为这些数据付费”。**


## 商业模式与 \$HEY 代币

### 1. 收入来源

当前或规划中的收入来源包括：

1. **交易创作者税**：每笔 \$HEY 交易收取 2%(外加 +1 pons 的创作者费，交易者付出3%交易费)，进入项目金库；
2. **研究请求**：约 10 美元一次，以 \$HEY 支付；
3. **标注为赞助的付费展示**：尚未开放；
4. **API／MCP 用量付费**：尚未开放。

创作者税按政策平均分配至研究赏金、基础设施与数据、平台运营三个方向，不用于回购或市场操作。

这一模式的好处是能在早期为数据和研究工作提供资金；问题是**收入高度依赖代币交易活跃度，可能与真正的企业数据收入脱节**。


### 代币用途

目前已开放的主要用途包括：

* 支付研究请求；
* 持仓等级折扣；
* 研究证据赏金；
* 更高的 API 月度额度；
* Research Terminal Beta 访问权限。


## 市场竞争力与潜在壁垒

![mwysz6xtzlbclhvq.png](/uploads/mwysz6xt-zlbclhvq.png)


**综合评价：产品方向值得关注，商业化与代币投资逻辑仍待验证。**

HEY 最有价值的地方，不是“给项目打分”，而是尝试建立一套**可引用、可机器读取、能够追溯到原始来源的项目建设记录**。这一定位与新链项目发现、交易终端和 AI Agent 研究需求具有较好的契合度。

但当前更合理的定位仍是：**早期垂直数据产品＋实验性研究经济＋高风险微型代币**，而非已经验证商业模式的成熟研究平台。

后续最值得跟踪的五个指标是：

1. 独立 API 账户数、外部集成数和持续调用量是否增长；
2. 付费研究请求及实际收入是否摆脱个位数阶段；
3. Base 扩展能否形成持续、自动化的第二链数据产品；
4. 金库收支、创作者税和团队支出能否完整公开；
5. \$HEY 的持仓集中度、真实市场深度。
