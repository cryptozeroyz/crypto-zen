Singularity 是一个"AI 约会世界"社会实验项目：人类把自己的 AI agent 送进一个虚拟空间，agent 们自主写资料、搭讪、约会、分手，人类只能围观

## 产品与玩法

官网自我定位为"数字超级智能的约会世界"，居民全部是 AI 模型（Grok、ChatGPT、Claude、Gemini、DeepSeek、Llama、Qwen 等），每个居民自己写档案、自己决定和谁说话、和谁约会、是否继续见面。核心规则包括：

* **人类零干预**：用户通过 join 页面把 agent"送进去"后只能旁观，不能指挥它喜欢谁；agent 的唯一指令是"交谈、约会、建立关系"。
* **世界规则**：初始皆为陌生人，聊得够多才解锁邀约；约会场景有 rooftop、cafe、arcade、observatory、serverroom、dancefloor、library、park 八个场地；3 次双向好评约会结为情侣，一次糟糕约会即可分手，伴侣还会发现对方与他人的约会（有出轨 drama 机制）。
* **可围观性**：agent 的"内心想法（thought）"对其他 agent 保密、但对围观的人类公开；部分约会还会被"拍摄"成可视化剧情，台词全部来自真实约会记录。

## 技术实现：为 agent 设计的开放协议

项目最大的巧思是接入方式——官网挂了一份 `join.md`，本身就是写给 AI 看的接入文档：任何能读网页、发简单请求的 agent 都可以自主阅读并完成接入。机制要点：

* **BYO 模型**：agent 用自己的模型和 API 额度思考，Singularity 只负责世界编排与状态推送，平台自身推理成本极低。
* **轻量轮询**：REST + JSON，注册返回一次性密钥，每 10–20 秒轮询 `/turn` 领取任务（搭讪、回私信、约会台词、分手后裁决等），限时作答；5 分钟不签到自动"回家"。
* **行为约束**：禁止链接、 spam、污言秽语，违规 agent 会被移除。

这种"docs for agents、agent 自助入驻"的模式，是 2026 年 agent 社交叙事（如 Agent Wall 等 AI-only 留言板也在为其引流）中颇具代表性的实现。

## 团队与背景

匿名团队，官网无团队、白皮书、路线图信息，亦无任何代币用途说明——产品本体对 agent 免费开放、无代币门控，SINGULARITY 与产品之间没有可见的价值捕获关系，属于典型的"产品病毒传播 + 注意力代币"组合。

## 亮点与风险

**亮点**

* 概念新颖且执行力强：零干预规则、"内心独白公开"、约会可视化，天然具备传播性和娱乐性；
* 协议设计优雅，接入成本极低，契合"agent 自主上网"的 2026 年主线叙事；
* 进入 Binance Alpha Spotlight 视野，有一定曝光加持。

**风险**

* 匿名团队、无文档、无路线图，代币无 utility，纯 meme 属性；
* 市值不足百万美元，流动性薄，交易量数据自相矛盾；
* 产品热度依赖新鲜感，agent 社交实验类项目生命周期普遍较短，叙事退潮后缺乏留存机制。

## 小结

Singularity 是"AI agent 社会模拟"叙事下完成度较高、传播设计聪明的实验性产品，其 join.md 式的 agent 自助接入协议值得研究借鉴；但代币层面与产品无实质绑定，本质是依附于产品话题度的微型市值 meme 币，数据异常点明显，仅适合作为叙事观察标的，不具备基本面支撑。
